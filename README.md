# Haraka Bingwa

Monorepo for the Haraka Bingwa storefront, admin panel, API, and bot.

## Apps
- Web storefront: apps/web
- Admin panel: apps/admin
- API: apps/api
- Bot: apps/bot

## Local development
- npm install
- npm run dev:web
- npm run dev:admin
- npm run dev:api
- docker compose up postgres
